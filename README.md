# 取了吗 · 版本发布仓库（qlm-release）

> 仓库用途：**只存放 APP 安装包与版本更新配置文件**，不含业务源码。
> 应用会定时读取本仓库根目录的 `version.json` 来判断是否有新版本并引导升级。

| 项目 | 说明 |
| --- | --- |
| 应用名称 | 取了吗（PickupAssistant） |
| 包名 | `com.hnu.pickupassistant` |
| 最新版本 | **3.0.1（versionCode 301）** |
| 支持系统 | Android 10 及以上（minSdk 29 / targetSdk 34） |
| 安装包命名 | `qlm_re_<版本号>.apk`，例：`qlm_re_3.0.1.apk` |
| 更新配置 | 根目录 `version.json`（App 直接读取，勿改名） |
| 技术栈 | Kotlin + Jetpack Compose（Material 3）+ ML Kit 中文离线 OCR |

「取了吗」是一款**纯本地**的快递取件码管理工具：把驿站短信、聊天记录或截图里的取件码一键收进列表，出门前扫一眼就知道去几号架取哪几个件，到驿站直接点开核销。

## 软件架构

单模块 Android 应用（`app`），Kotlin + Jetpack Compose 声明式 UI，MVVM 思路，状态用 `StateFlow` 单向流动，本地持久化用 `SharedPreferences` + 应用私有目录文件，**无服务端、不联网上传任何数据**（除更新检查）。

```
┌──────────────────────── UI 层（ui/） ────────────────────────┐
│ MainScreen　设置弹窗　识图预览弹窗　截图预览　主题令牌            │
│ HyperTheme（qlm_* 语义色，深浅色双套）                          │
└───────────────▲──────────────────────────────┬───────────────┘
                │ StateFlow 订阅                │ 用户事件
┌───────────────┴──────────────────────────────▼───────────────┐
│ 数据/领域层（data/ model/ util/）                              │
│ LocalStorageManager（唯一数据源：列表 / 开关 / 常用驿站 / 快捷按钮）│
│ PickupCodeMatcher　OutboundCodeDetector　PickupItemFormatter    │
└───────────────▲──────────────────────────────┬───────────────┘
                │                              │
┌───────────────┴───────────┐   ┌──────────────▼───────────────┐
│ OCR 识别（ocr/）           │   │ 系统能力（service/ shizuku/） │
│ OcrHelper 图像增强/分片    │   │ 悬浮窗　屏幕截图　快捷磁贴     │
│ ParcelBlockParser 区块切分 │   │ ClipboardReadActivity 剪贴板  │
│ PickupRegexRules 规则集    │   │ 更新模块 update/（8 个类）     │
└───────────────────────────┘   └──────────────────────────────┘
```

### 软件架构说明

| 目录 | 职责 |
| --- | --- |
| `ui/` | Compose 界面与主题；`MainScreen` 主列表、`SettingsDialog` 设置、`HyperTheme` 语义色 + 三档 dimens |
| `data/` | `LocalStorageManager` 全局数据门面（`init()` 后以 Flow 暴露，写入即持久化），无数据库 |
| `model/` | `PickupItem`（驿站 / 货架 / 单号 / 备注 / 是否待办 / 是否已取）与快捷按钮模型 |
| `ocr/` | ML Kit 中文离线识别封装：图像增强、长图分片、区块切分、文本归一化、规则匹配、识图与截图预览 |
| `service/` | 悬浮窗（`TYPE_APPLICATION_OVERLAY`，单窗口，宽高锁定）、屏幕截图前台服务、控制中心磁贴 |
| `shizuku/` | 通过 Shizuku 授权的免弹窗截屏通道（未授权时自动回退系统截屏） |
| `update/` | 在线更新：检查（6 小时限流 + 防降级）、下载（带 Referer、断点重试）、校验（文件 / ZIP / 签名匹配）、落盘到公共【下载】目录、唤起安装器 |
| `util/` | 剪贴板/文本解析、取件码匹配、出库码检测、展示格式化、Bitmap 采样解码 |

**更新链路**：`MainActivity.onCreate` → `UpdateChecker`（读 `version.json`、比较 `versionCode`、`VersionRules` 防降级）→ `ApkDownloader`（OkHttp，显示进度）→ `PublicDownloadStore`（MediaStore 写入公共下载目录、校验完整性）→ `UpdateManager`（`FileProvider` Uri 唤起系统安装器，失败回退文件管理器）。`forceUpdate=true` 时弹窗不可取消。

**隐私**：识别全部在设备本地完成（ML Kit 离线模型），不上传、不保存原始截图；仅更新检查会访问网络。

## 安装教程

1. **下载安装包**：在本仓库 `Releases` 或根目录找到最新的 `qlm_re_<版本号>.apk`（例：`qlm_re_3.0.1.apk`），点击下载。
2. **允许安装**：首次安装时系统会提示「未知来源应用」，请在弹窗中选择允许（或在「设置 → 应用 → 特殊权限 → 安装未知应用」中给浏览器/文件管理器授权），然后点击「安装」。
3. **覆盖升级**：已装旧版时**直接覆盖安装即可**，所有版本使用同一签名证书（SHA-256 `05e33049…`），本地取件码数据会保留；**不要先卸载**，卸载会清空数据。
4. **首次启动授权**：进入 App 后按需授予「悬浮窗权限」（设置 → 应用 → 显示在其他应用上层）与「通知权限」；需要使用「看见没」磁贴截图识别时，再装 Shizuku 并授权（不装也能用其它入口）。

## 使用说明

1. **粘贴文字添加**：复制驿站短信/聊天记录，回到 App 点「粘贴文字」（或直接在输入框粘贴），自动解析出驿站、货架号、取件码并入库；一次可粘贴多条。
2. **识图添加**：点「识图添加」选相册截图，自动识别菜鸟驿站、妈妈驿站、驿站列表页、多包裹详情页等常见布局；识别结果弹窗可逐条勾选、**驿站 / 快递公司 / 单号 / 备注均可二次修改**后保存。下拉控制中心添加「看见没」磁贴，可一键识别当前屏幕（本地识别，不上传不保存截图）。
3. **待办与核销**：输入框可添加纯文字待办（如「取完顺便寄件」）；取件码卡片**点击即核销**，左滑删除有 5 秒撤销倒计时；顶部统计条可一键清理已取件/已完成。
4. **悬浮小窗**：开启后桌面常驻一张白色磨砂卡片，显示「待取 / 待办」列表与货架分组，可拖动、折叠；点码核销、长按复制取件码、「读取剪贴板」直接导入；「出库码」按钮打开驿站出库码（可设置静态截图兜底，无信号时全屏高亮展示）。
5. **设置**：维护常用驿站（参与识别匹配）、配置快捷按钮与出库码路由、悬浮窗是否显示待办、深浅色跟随系统、手动检查更新。

## 更新配置（version.json）

放在本仓库根目录，App 启动时读取（最长 6 小时一次，设置页可手动检查）：

```json
{
  "versionCode": 301,
  "versionName": "3.0.1",
  "apkUrl": "https://.../qlm_re_3.0.1.apk",
  "forceUpdate": true,
  "updateLog": "本次更新说明，显示在更新弹窗中",
  "releaseTime": "2026-11-12"
}
```

| 字段 | 说明 |
| --- | --- |
| `versionCode` | 整数，必须**大于**用户当前版本才会提示（规则：`X.Y.Z` 拼接为三位，如 3.0.1 → 301） |
| `versionName` | 展示用版本名，与 APK 内一致 |
| `apkUrl` | APK 直链，**必须可直连下载**（Gitee Release 附件直链或自建存储） |
| `forceUpdate` | `true` 时更新弹窗不可关闭（用于影响使用的严重缺陷） |
| `updateLog` | 更新说明，纯文本 |
| `releaseTime` | 发布日期 |

> 发布新版本时：上传 APK → 把直链填入 `apkUrl` → 覆盖根目录 `version.json`（三个字段与 APK 内 `versionCode/versionName` 必须完全一致）。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 收不到更新提示 | 更新检查 6 小时限流，可在设置页点「检查更新」；确认线上 `version.json` 的 `versionCode` 大于已装版本 |
| 安装失败「应用未安装」 | 多为签名不一致（装过第三方改包）或未授权未知来源；建议备份后卸载旧包再装 |
| 桌面/悬浮窗异常 | 确认已授予「显示在其他应用上层」；国产 ROM 需在电池管理中允许后台运行 |
| 识图没识别出来 | 保证截图完整包含取件码区块、不过度缩放；可在识别结果弹窗手动补录 |
| 换机后数据丢失 | 数据仅存本机（不含云同步），换机前请手动抄录或保留旧机 |
